Before you build a sales plan in Claude

Turn on web search (tools button under Claude’s message box) and code execution (Settings, then Capabilities, then Code execution and file creation). This works on Free, Pro and company plans. A Free plan usually covers one or two sales plans before Claude pauses you for a few hours, so Pro is better for regular prospecting. If Claude opens with an empty message box, click in it and paste (Ctrl+V or Cmd+V); the request is copied for you.
